# Security policy

## Supported scope

Report vulnerabilities that affect the published site, its GitHub Actions workflows, or the local credential-lifecycle laboratory in `poc/`.

The laboratory uses disposable local credentials and data. Do not submit a real credential, personal data, or confidential material as part of a report.

## Reporting a vulnerability

Use a [private GitHub security advisory](https://github.com/llody9977/secret-exposure/security/advisories/new). Include the affected path, a minimal reproduction, expected and observed behavior, and any practical impact.

Do not open a public issue until a maintainer confirms that disclosure is appropriate.
